# 手写 BP 算法与代码阅读说明

本文解释实现，不包含未经运行的实验结果。正式对照报告由运行记录生成。

## 1. 数据与张量形状

每个样本有 4 个数值特征，类别为 1、2、3。内部标签改成 0、1、2，便于数组索引；保存和展示时恢复原标签。

以 `4→8→3` 为例，批大小为 B：

| 变量 | 形状 | 含义 |
| --- | --- | --- |
| X | B × 4 | 标准化后的输入 |
| W1 / b1 | 4 × 8 / 8 | 第一层权重、偏置 |
| Z1 / A1 | B × 8 | 隐藏层净输入、激活值 |
| W2 / b2 | 8 × 3 / 3 | 输出层权重、偏置 |
| Z2 / P | B × 3 | 分类得分、类别概率 |

## 2. 前向传播

隐藏层：`Z1 = X @ W1 + b1`，`A1 = f(Z1)`。

输出层：`Z2 = A1 @ W2 + b2`，`P = softmax(Z2)`。

多隐藏层时重复同样的仿射变换和激活。激活函数与导数：

| 函数 | 激活 | 导数 |
| --- | --- | --- |
| Sigmoid | `a = 1 / (1 + exp(-z))` | `a * (1-a)` |
| Tanh | `a = tanh(z)` | `1-a²` |
| ReLU | `a = max(0,z)` | `z > 0` 时为 1，否则为 0 |

ReLU 在 0 处不可导，实现取 0。数值梯度检查应避免落在这个折点上。

## 3. Softmax 与交叉熵

每行先计算 `s = z - max(z)`，再计算 `p_k = exp(s_k) / sum(exp(s))`。减最大值不改变概率，可以避免指数溢出。

直接计算 `log_p = s - log(sum(exp(s)))`，平均交叉熵为：

`L_data = -sum(log_p[i, y_i]) / B`。

这样不需要对非常小的概率先裁剪再取对数，损失函数与解析梯度保持一致。

可选 L2 正则：`L = L_data + λ/2 * Σ||W_l||²`。偏置不正则化。默认 λ=0，主实验未混入正则化因素。

## 4. 反向传播

对输出层，Softmax 和交叉熵组合后的导数可以化简为：

`delta_L = (P - one_hot(y)) / B`。

任一层的梯度：

`dW_l = A_(l-1).T @ delta_l + λ * W_l`。

`db_l = sum(delta_l, axis=0)`。

反传到前一隐藏层：

`delta_(l-1) = (delta_l @ W_l.T) * f'(Z_(l-1))`。

这些公式对应 `src/network.py` 中的 `loss_and_gradients()`。代码先算出所有层的梯度，之后 `step()` 才执行 `W -= learning_rate * dW` 和 `b -= learning_rate * db`。

## 5. 初始化、批训练和随机性

默认 Xavier 均匀初始化：`W ~ U(-sqrt(6/(fan_in+fan_out)), +sqrt(6/(fan_in+fan_out)))`，偏置初始化为 0。

也支持 He 初始化：隐藏层 `W ~ Normal(0, sqrt(2/fan_in))`。激活函数对照实验默认仍全部使用 Xavier，使主对照只改变激活函数。

每轮只打乱训练集，分成小批量计算梯度、执行 SGD。`batch_size=0` 表示全批量。相同 epoch 下，小批量通常执行更多次参数更新，所以结果同时记录更新次数。

CPU 和 GPU 共享 CPU 生成的初始化参数及打乱顺序，减少随机实现差异，但浮点运算顺序仍可能引起细微差异，不承诺逐位相同。

## 6. 为什么需要梯度检查

中央差分近似某个参数的导数：

`g_numeric = (L(theta+h) - L(theta-h)) / (2h)`。

使用 float64 和小网络逐参数比较解析梯度与数值梯度，可以发现平均系数、转置、激活导数和 L2 项的错误。`src/validation.py` 提供三种激活函数的检查，以及多隐藏层 CPU/GPU 数值对照；`tests/test_bp.py` 还包含独立的多层方向导数检查。

## 7. 数据与评价原则

- 过滤训练集中与测试集完全相同的记录，得到 74 条建模数据。
- 固定分层取每类 5 条验证记录，剩余 59 条用于对照实验。
- 每个训练子集单独拟合标准化，验证集和测试集只做 transform。
- 训练数据量组按类别使用同种子排列的前缀，所以小子集嵌套于大子集。
- 类别比例组均衡 `[10,10,10]` 与偏斜 `[15,10,5]`，总量同为 30（按当前默认划分）。
- 最终配置按多种子验证宏 F1、验证准确率、验证交叉熵依次排序；再以参数量、条件名打破并列。
- 最终在完整 74 条上重训，重新拟合标准化，最后评估 75 条测试数据。
- 宏 F1 对各类同等加权；类别比例实验同时报告每类召回率，避免只看准确率掩盖少数类问题。

测试集每错一条，准确率约变化 1.33 个百分点。固定验证划分下的多种子标准差，不等于面对全新数据的泛化误差范围。
